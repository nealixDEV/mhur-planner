CSS DESIGN INSTRUCTIONS
GOLD + DARK RED HUD INTERFACE

Use this document as a reusable visual brief for a different project.


1. OVERALL DESIGN DIRECTION

Create a premium dark HUD interface with a gold and dark-red color system.
The visual style should feel tactical, dramatic, polished, and information-dense without becoming cluttered.

Use these design ideas consistently:
- Dark red-black atmospheric background
- Warm gold for hierarchy, selected states, headings, and important actions
- Deep wine and burgundy surfaces instead of blue panels
- Glassy layered panels with subtle borders and inner highlights
- Compact cards with strong alignment and clear information hierarchy
- Sharp but restrained glow effects
- Light motion on hover and page entrance
- Strong desktop layout that collapses cleanly on mobile

Do not use a generic flat dashboard, plain white cards, excessive rounded pills, or random gradients.
Every color and effect should support hierarchy or interaction feedback.


2. COLOR SYSTEM

Define the palette as CSS variables so the theme can be changed easily.

:root {
  --bg-0: #120708;
  --bg-1: #220b0d;
  --bg-2: #3a1014;
  --bg-3: #57161b;

  --panel-0: rgba(24, 8, 10, 0.96);
  --panel-1: rgba(45, 12, 16, 0.92);
  --panel-2: rgba(74, 20, 25, 0.82);
  --panel-glass: rgba(105, 31, 37, 0.35);

  --gold-0: #fff0a3;
  --gold-1: #f5d35e;
  --gold-2: #e5ad24;
  --gold-3: #9b6710;

  --red-0: #ff6670;
  --red-1: #e33b46;
  --red-2: #a51f2b;
  --red-3: #64131b;

  --text-0: #fff7e2;
  --text-1: #eadbd0;
  --text-2: #c19e98;
  --text-muted: #987875;

  --line-soft: rgba(255, 220, 150, 0.12);
  --line-gold: rgba(245, 211, 94, 0.45);
  --line-red: rgba(227, 59, 70, 0.42);
  --shadow-dark: rgba(0, 0, 0, 0.55);
  --glow-gold: rgba(245, 211, 94, 0.24);
  --glow-red: rgba(227, 59, 70, 0.2);
}

Palette rules:
- Gold is the primary accent, not a background color.
- Use dark red surfaces with enough contrast between levels.
- Keep body text warm off-white, not pure white everywhere.
- Use bright red only for errors, danger, destructive actions, or urgent status.
- Do not use blue, cyan, or purple as primary UI colors.
- Green may be used only for success or positive status.


3. PAGE BACKGROUND

Use a layered background instead of a single flat color.

Recommended structure:
- Base: very dark red-black
- Large slow-moving diagonal gradient using burgundy and oxblood
- Optional low-opacity texture or illustration overlay
- Fixed overlay must have pointer-events: none

Example:

body {
  min-height: 100vh;
  color: var(--text-0);
  background:
    radial-gradient(circle at 12% 8%, rgba(130, 30, 40, 0.24), transparent 34%),
    radial-gradient(circle at 88% 18%, rgba(245, 211, 94, 0.07), transparent 28%),
    linear-gradient(135deg, var(--bg-0), var(--bg-1) 48%, var(--bg-2));
  background-size: 180% 180%;
  animation: backgroundDrift 24s ease infinite;
  font-family: "Rajdhani", "Segoe UI", sans-serif;
}

Keep background animation slow and subtle. Never let it reduce readability.


4. TYPOGRAPHY

Use two type roles:
- Display headings: geometric, condensed, uppercase, high weight
- Interface text: clean sans-serif with strong readability

Recommended choices:
- Headings: Futura, Century Gothic, Rajdhani, or a similar geometric font
- Body/UI: Rajdhani, Segoe UI, Inter, or another readable sans-serif

Typography rules:
- Main headings use uppercase lettering and moderate tracking.
- Use gold gradient text only for major headings and high-value labels.
- Keep paragraph text between 0.85rem and 1rem on desktop.
- Use at least 0.9rem for important mobile text.
- Use line-height around 1.45 to 1.7 for descriptions.
- Use muted text for metadata, never for primary actions.

Example gold heading:

.gold-heading {
  background: linear-gradient(135deg, var(--gold-0), var(--gold-2), var(--gold-1));
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
  filter: drop-shadow(0 0 10px var(--glow-gold));
}


5. LAYOUT

Use a spacious, structured layout:
- Center the main content with a max-width between 1100px and 1600px.
- Use CSS Grid for major page regions.
- Use Flexbox for toolbars, chips, metadata, and button groups.
- Maintain 10px to 16px gaps between major panels.
- Keep content aligned to a consistent vertical rhythm.

Desktop:
- Use two or three columns when the content benefits from comparison.
- Keep the main content column flexible.
- Keep side panels narrow enough that the primary content remains dominant.

Mobile:
- Collapse multi-column layouts to one column.
- Keep controls large enough to tap.
- Allow cards to become a responsive grid.
- Avoid horizontal scrolling except for intentionally scrollable data tables.
- Preserve section order and visual hierarchy.


6. PANELS AND CARDS

Panels should look layered and slightly translucent.

Recommended panel treatment:

.panel {
  background: linear-gradient(145deg, var(--panel-2), var(--panel-0));
  border: 1px solid var(--line-soft);
  border-radius: 12px;
  box-shadow:
    0 10px 32px var(--shadow-dark),
    inset 0 1px 0 rgba(255, 245, 210, 0.07);
  backdrop-filter: blur(8px);
}

Panel rules:
- Use a gold top border or left border for important panels.
- Use a red border for danger, active combat, or urgent status.
- Keep panel backgrounds darker than their surrounding background.
- Do not give every card a different visual style.
- Use one primary panel style and one compact card style.

Section headers should use:
- Uppercase text
- Gold color or gold gradient
- Letter spacing around 0.06em to 0.12em
- A thin gold divider or accent line


7. GOLD ACCENTS

Use gold for:
- Page titles
- Section titles
- Selected character/card outlines
- Active tabs
- Primary buttons
- Important values
- Dividers and small HUD markers

Use gold sparingly. The interface should feel dark first and gold second.

Recommended divider:

.gold-divider {
  height: 2px;
  background: linear-gradient(90deg, transparent, var(--gold-2), transparent);
  opacity: 0.8;
}


8. DARK-RED ACCENTS

Use dark red for:
- Panel depth and hierarchy
- Secondary backgrounds
- Active danger states
- Destructive actions
- Combat or alert areas
- Hover shadows for aggressive sections

Recommended red panel:

.red-panel {
  background: linear-gradient(145deg, rgba(105, 26, 34, 0.62), rgba(30, 7, 10, 0.96));
  border: 1px solid var(--line-red);
  box-shadow: 0 8px 28px var(--shadow-dark), 0 0 20px var(--glow-red);
}

Do not make every panel bright red. Use burgundy for most surfaces and reserve bright red for interaction feedback.


9. ROSTER AND CHARACTER CARDS

Roster cards should feel like collectible tactical cards:
- Portrait or artwork fills the card.
- Use a dark gradient from transparent at the top to nearly black at the bottom.
- Put the character name at the bottom with strong contrast.
- Add a subtle color wash based on category or role.
- Use a gold outline and gold glow for the selected card.
- Use a small upward hover motion.

Example:

.roster-card {
  position: relative;
  overflow: hidden;
  aspect-ratio: 0.8;
  border: 1px solid var(--line-soft);
  border-radius: 10px;
  background: var(--panel-1);
  box-shadow: 0 4px 16px var(--shadow-dark);
  transition: transform 0.15s ease, border-color 0.15s ease, box-shadow 0.15s ease;
}

.roster-card:hover {
  transform: translateY(-3px) scale(1.02);
  border-color: var(--line-gold);
  box-shadow: 0 8px 22px var(--shadow-dark), 0 0 16px var(--glow-gold);
}

.roster-card.selected {
  outline: 2px solid var(--gold-1);
  outline-offset: -2px;
  box-shadow: 0 0 24px var(--glow-gold), 0 8px 24px var(--shadow-dark);
}


10. TABS AND NAVIGATION

Tabs should feel like a command console:
- Dark transparent base
- Gold active underline or border
- Gold text for the active tab
- Red hover shadow only where appropriate
- Clear focus state for keyboard users

Inactive tab:
- Muted warm text
- Low-opacity border
- Transparent or dark-red background

Active tab:
- Gold text
- Gold border or underline
- Slight gold translucent background
- Small glow, not a large neon effect


11. BUTTONS AND CONTROLS

Primary button:
- Gold gradient background
- Dark red or near-black text
- Strong font weight
- Slight inset shadow
- Hover becomes lighter gold

Secondary button:
- Transparent dark-red background
- Gold or muted border
- Warm light text

Danger button:
- Dark red gradient
- Light text
- Red glow on hover

Button interaction:
- Use a 0.12s to 0.2s transition.
- Add a small upward movement on hover.
- Add a visible focus outline.
- Keep minimum touch height around 38px on mobile.


12. INPUTS, SELECTS, AND SEARCH

Inputs should match the panel system:
- Near-black or dark burgundy background
- Thin low-opacity gold border
- Warm off-white text
- Gold focus border and soft glow
- Muted placeholder text

Do not use browser-default bright white fields.

Example:

input,
select,
textarea {
  background: rgba(18, 7, 8, 0.88);
  color: var(--text-0);
  border: 1px solid rgba(245, 211, 94, 0.28);
  border-radius: 6px;
}

input:focus,
select:focus,
textarea:focus {
  border-color: var(--gold-1);
  outline: none;
  box-shadow: 0 0 12px var(--glow-gold);
}


13. STATUS TAGS

Use compact tags for categories and metadata.

Tag rules:
- Uppercase text
- Small font size
- High font weight
- 3px to 5px radius
- Use role-specific dark-red/gold shades
- Keep tags readable at a glance

Suggested tag meanings:
- Gold: selected, featured, premium, important
- Dark red: danger, villain, destructive, urgent
- Burgundy: neutral category or secondary information
- Green: success or completed state only


14. DATA TABLES AND DENSE INFORMATION

For dense data:
- Use dark alternating row backgrounds.
- Use gold for column headers and key numbers.
- Use thin burgundy separators.
- Keep rows compact but readable.
- Highlight the active row with a translucent gold background.
- Highlight warnings with dark red, not bright red everywhere.

Never sacrifice readability for a more dramatic HUD appearance.


15. MODALS AND OVERLAYS

Modal overlays should use:
- Nearly black translucent backdrop
- Centered dark-red panel
- Gold top or left accent border
- Soft shadow and backdrop blur
- Clear close button in the upper-right corner

Use a short fade and upward entrance animation. Keep modal content scrollable on mobile.


16. MOTION

Use motion to communicate state, not decoration.

Recommended motion:
- Page sections fade upward on entrance.
- Cards lift slightly on hover.
- Selected items receive a soft gold glow.
- Alerts use a restrained red pulse.
- Background movement should be slow and nearly imperceptible.

Avoid constant bouncing, aggressive flashing, or animations that compete with data.

Respect reduced motion preferences:

@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}


17. RESPONSIVE RULES

Desktop:
- Use compact cards and multiple columns.
- Keep the main content visually dominant.
- Use sticky side panels only when they improve navigation.

Tablet:
- Reduce column count before reducing text size.
- Keep panels comfortable to scan.

Mobile:
- Use one-column layouts.
- Increase button and input height.
- Use a smaller but still readable roster grid.
- Keep gold headings visible and avoid excessive letter spacing.
- Let long names wrap or truncate cleanly.
- Avoid fixed-width panels that create horizontal overflow.


18. ACCESSIBILITY

Maintain readable contrast between text and dark red surfaces.
Do not communicate state by color alone.
Add text, icons, borders, or labels for selected, danger, success, and disabled states.
Keep keyboard focus visible with a gold outline.
Use semantic buttons and labels instead of clickable generic divs where possible.
Use alt text for portraits and meaningful images.


19. IMPLEMENTATION RULES

- Put all theme colors in CSS variables.
- Keep component styles scoped with predictable class names.
- Prefer CSS Grid and Flexbox over absolute positioning for layout.
- Use absolute positioning only for overlays, badges, artwork, and decorative effects.
- Keep shadows layered but subtle.
- Avoid adding a new gradient for every component.
- Reuse panel, card, button, tag, and input patterns.
- Test the layout at desktop width and narrow mobile width.
- Check that long text, missing images, and empty states still look intentional.


20. SHORT DESIGN PROMPT

Build a premium tactical HUD interface using a dark red-black background and warm gold accents. Use layered burgundy glass panels, thin translucent borders, compact information cards, gold uppercase section headings, dark-red danger states, and subtle shadows. Make roster cards feel like collectible tactical cards with image backgrounds, gradient overlays, selected gold outlines, and small hover lifts. Use gold for hierarchy and interaction, not as a full-page background. Keep the layout responsive, readable, keyboard accessible, and visually consistent. Avoid blue, cyan, purple, flat white dashboards, excessive pills, and random gradients.
